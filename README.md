# Todo App

A command-line based Todo List application built with Python, designed as an evolving project to practice and apply core software engineering concepts.

This repository represents **Version 1.0 (CLI, in-memory)** of the Todo App and will be incrementally extended to include file persistence, object-oriented design, database integration, and web/desktop interfaces.

---

## 🚀 Features (v1.0)

- Add new tasks
- Update existing tasks
- Mark tasks as completed
- Delete tasks
- View all tasks
- Robust command parsing
- Input validation and error handling
- Clear separation between logic and UI

---

## 🛠️ Technologies Used

- Python 3
- Standard Library only (no external dependencies)

---
